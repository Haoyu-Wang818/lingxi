# ADR 0002：情境引擎先用可解释规则，而非训练模型

- 状态：已采纳
- 日期：2026-11-19

## 背景

判断「可学习时刻」没有现成标注数据；评审与用户也需要知道系统为什么在此刻打扰。

## 决定

`LearnableMomentDetector` 采用「硬性阻止 + 证据加权打分 + 心率负荷评估」三步规则，每条证据带权重与中文描述。
收集到用户对推送的接受/忽略反馈后，再用其训练轻量分类器替换打分部分，接口 `evaluate(ContextSignals)` 不变。

## 影响

- 现场演示可直接展示每条依据；情境实验室页面可手动调节信号。
- 权重为经验值，P2 阶段需用真实使用数据校准。
