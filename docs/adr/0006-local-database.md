# ADR 0006：本地数据库采用 Room（KSP）

- 状态：提议
- 日期：2026-11-21
- 关联需求：SRS 第 5 节、FR-AI-05、NFR-AVAIL-01

## 背景

手机是唯一的数据中心，需要关系型存储（知识点与关系、卡片与记忆状态、日志）、事务、迁移和 Flow 观察。

## 备选

| 方案 | 结论 |
| --- | --- |
| **Room + KSP** | 官方、编译期 SQL 校验、Flow 支持、迁移测试工具完善 |
| SQLDelight | 跨平台、SQL 优先，但本项目无跨平台需求 |
| ObjectBox / Realm | 非关系型，图谱查询与追溯不便；许可证与体积顾虑 |

## 决定

`core:data` 使用 Room，开启 `exportSchema` 并把 schema JSON 纳入版本库，用于迁移测试与设计文档核对。图谱遍历（先修链）用递归 CTE 查询。
