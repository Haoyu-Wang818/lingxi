# ADR 0004：依赖注入使用手写 AppContainer

- 状态：提议
- 日期：2026-11-21
- 关联需求：NFR-MAINT-01、NFR-PERF-03

## 背景

模块增多后需要统一装配仓库、路由、网关客户端等对象。项目由 AI 生成代码，构建链越简单，出错越少、评审越容易。

## 备选

| 方案 | 优点 | 缺点 |
| --- | --- | --- |
| Hilt | 业界标准、作用域完善 | 注解处理增加构建时间；生成代码难以评审；AGP 新版本兼容需跟进 |
| Koin | 轻量、运行时 | 运行时解析，错误到运行时才暴露 |
| **手写 `AppContainer`** | 零依赖、显式、编译期检查、易于测试替换 | 需手写装配代码 |

## 决定

在 `app` 中实现 `AppContainer`，按功能暴露工厂；`feature` 模块通过构造参数接收依赖，测试中直接传入假实现。若后期装配代码超过约 300 行再评估迁移 Hilt。
