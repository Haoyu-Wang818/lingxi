## 1. 引言

### 1.1 目的

本文档定义「灵犀学伴」初赛 Beta 及复赛版本应满足的功能与非功能需求，是概要设计、详细设计、测试计划的唯一输入。
需求一经评审冻结（tag `v0.1-srs`），修改需在第 7 节变更记录中登记。

### 1.2 编号与优先级约定

- 功能需求：`FR-<模块>-<序号>`；非功能需求：`NFR-<类别>-<序号>`。
- 优先级采用 MoSCoW：**M** 必须（初赛 Beta）、**S** 应该（初赛尽量）、**C** 可以（复赛）、**W** 本届不做。
- 每条需求带「验收条件」，测试用例直接由它导出；代码 KDoc 与测试 `@DisplayName` 引用需求编号。

### 1.3 术语

| 术语 | 含义 |
| --- | --- |
| 捕获 | 一次拍照、录音或导入 PDF 的动作及其素材 |

| 链路 | 手机与手表之间的一种通信方式，实现 `WatchLink` |

## 2. 总体描述

### 2.1 产品视角

系统采用**手机优先**策略：卡片式复习等核心体验在手机上完成，手表作为复习推送和小屏作答的加分项（依据问卷：61% 受访者不戴智能手表）。
系统由手机 App、手表 App（Wear OS 版与华为轻穿戴版）、云端网关三部分组成。
手机是数据中心，本地数据库保存全部用户数据；网关无状态，只转发大模型请求和手表中继消息，不保存用户内容。

### 2.2 运行环境

| 端 | 环境 |
| --- | --- |
| 手机 | Android 10（API 29）及以上，含无 Google 服务的 HarmonyOS 4.0 兼容层；参考机 HUAWEI Mate 20 Pro |
| 手表 | Wear OS 4 及以上（模拟器、OPPO 手表）；HUAWEI WATCH GT 5（HarmonyOS 6.0，轻穿戴） |
| 网关 | Python 3.12、FastAPI；开发期运行在本地 Mac |
| 大模型 | 通义千问（DashScope 兼容 OpenAI 接口） |

初赛在 Mac 上的手机与手表模拟器演示；真机部署（HUAWEI Mate 20 Pro、决赛演示手表）在 2027 年 2 月完成验证。

### 2.3 设计约束

- C1 禁止依赖 ML Kit、Firebase。Google Play 服务仅允许用于手表同步（Wear Data Layer），且只能出现在独立模块 `sync-datalayer` 中，缺失时自动切换到网关中继（ADR 0007）。
- C2 手机端不得持有大模型 API Key。
- C3 业务代码调用模型只能经过 `InferenceRouter`。
- C4 不依赖 Android 的逻辑放在 JVM 模块，可脱离 SDK 测试。
- C5 材料匿名：不出现学校与成员姓名。
