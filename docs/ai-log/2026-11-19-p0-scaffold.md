# 2026-11-19 P0 项目骨架

## 目标

根据赛题要求确定选题与架构，搭建可测试的项目骨架。

## 关键决策

- 选题「灵犀学伴」，赛道 AI 赋能学习生产力；三项核心创新：碎片时间情境引擎、课堂内容到知识图谱、端云协同隐私路由。
- 核心算法放纯 Kotlin/JVM 模块，无 Android SDK 也能测试（ADR 0001）。
- 情境引擎先用可解释规则（ADR 0002）。
- 国内手机无 Google 服务，OCR、语音识别选离线开源方案。
- 测试方法改用英文名 + `@DisplayName` 中文描述：中文方法名在非 UTF-8 环境下编译失败。

## 产出

- `core:model`、`core:ai`、`core:review`、`context-engine` 及 32 个单元测试
- `app`、`wear` 原型界面（待在有 SDK 的环境编译验证）
- `server` 网关及 7 个测试
- CLAUDE.md、README、架构文档、ADR、开源组件清单、CI
