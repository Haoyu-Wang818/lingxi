## 误差分析

主要错误是公式里的形近符号：x 识别成 ×、0 识别成 O、ln 识别成 In、省略号 … 识别成 `...`，另有个别空格。
中文正文几乎全部正确。这些识别文本随后会交给云端整理成笔记，大模型能结合上下文纠正大部分此类错误；
如果以后要在端侧纠正，可以在公式区域加一条「× 两侧都是字母或数字时还原为 x」的规则。

注意：测试图由电脑字体渲染（`scripts/make_board_fixtures.py`），比手写板书清晰，结果偏乐观；
SRS 的验收集是 20 张真实板书，需要等队友提供实拍照片后再评测一次。

## 识别结果与标准答案对照

### board-1

标准答案：

```
第五讲 泰勒公式
设f(x)在x0处有n阶导数，则
f(x)=f(x0)+f'(x0)(x-x0)+…+Rn(x)
佩亚诺余项：Rn(x)=o((x-x0)^n)
拉格朗日余项的中值介于x0与x之间
当x0=0时称为麦克劳林公式
```

识别结果：

```
第五讲泰勒公式
设f(x)在xO处有n阶导数，则
f(x)=f(x0)+f"(x0)(x-x0)+··+Rn(x)
佩亚诺余项： Rn(x)=o((x-x0)^n)
拉格朗日余项的中值介于x0与×之间
当x0=0时称为麦克劳林公式
```

### board-2

标准答案：

```
常用的麦克劳林展开
e^x=1+x+x^2/2!+x^3/3!+…
sin x=x-x^3/3!+x^5/5!-…
cos x=1-x^2/2!+x^4/4!-…
ln(1+x)=x-x^2/2+x^3/3-…
例：lim(x→0)(x-sin x)/x^3=1/6
```

识别结果：

```
常用的麦克劳林展开
e^x=1+×+×^2/2!+×^3/3!+...
sin x=×-x^3/3!+x^5/5!...
cOsx=1-x^2/2!+x^4/4!-..
In(1 +×)=×-x^2/2+x^3/3-.
例: lim(x→0)(x-sin x)/x^3=1 /6
```
